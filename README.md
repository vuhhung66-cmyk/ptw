# Photo Wheel 10K

Vòng quay ảnh chạy hoàn toàn bằng HTML/CSS/JavaScript, phù hợp GitHub Pages.

## Cách dùng

1. Tạo repository mới trên GitHub.
2. Upload `index.html`, `style.css`, `app.js`.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**.
5. Chọn branch `main`, folder `/ (root)`, rồi Save.
6. Mở link GitHub Pages.
7. Bấm **Chọn thư mục ảnh** và chọn thư mục chứa ảnh.
8. Tối đa 10.000 ảnh.
9. Bấm **QUAY**. Khi dừng sẽ hiện ảnh + tên file.

## Lưu ý

Ảnh không được upload lên server. Trình duyệt tạo URL tạm cho ảnh được chọn trên máy.

10.000 ô trên một vòng tròn không thể nhìn riêng từng ảnh ở kích thước màn hình thông thường; vòng quay vẫn dùng đủ 10.000 ảnh làm dữ liệu lựa chọn. Ảnh trúng được hiển thị rõ ở phần kết quả.
